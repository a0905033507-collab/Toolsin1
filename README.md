# 🔖 网站整合工具 (Website Aggregator)

一个智能的网站整合与管理工具，帮助你更好地组织和访问常用网站。

## ✨ 主要功能

### 1. 网站存储与管理
- 📝 输入网址即可快速添加网站
- 🏷️ 自动或手动设置网站名称
- 🗑️ 简单的删除操作

### 2. 智能图标获取
- 🎨 自动获取网站的标志性图标(favicon)
- 📱 支持多种图标格式和来源
- 🔄 图标加载失败时自动使用默认图标

### 3. 自动分类系统
- 🤖 基于网站内容和URL智能分类
- 📊 支持的分类包括：
  - 社交媒体
  - 开发工具
  - 搜索引擎
  - 新闻资讯
  - 电商购物
  - 视频娱乐
  - 教育学习
  - 设计创意
  - 生产力工具
  - 金融理财
  - 其他/未分类

### 4. 分类筛选
- 🔍 按分类快速筛选网站
- 🎯 清晰的分类标签展示

### 5. 相似度检测
- ⏰ 每周自动检查相似网站
- 🔗 智能识别重复或相似的网站
- 💡 提供合并/删除/忽略建议
- 📈 基于多维度计算相似度：
  - URL相似度
  - 网站名称相似度
  - 内容相似度
  - 分类相同性

## 📖 使用指南

### 添加网站

1. 在顶部输入框中输入完整的网址（如：https://www.google.com）
2. 可选：输入自定义网站名称
3. 点击"添加网站"按钮
4. 系统将自动获取图标并分类

### 访问网站

- 点击任意网站卡片即可在新标签页打开该网站

### 筛选网站

- 使用分类下拉菜单选择特定分类
- 选择"全部分类"查看所有网站

### 处理相似度建议

1. 当有相似网站建议时，顶部会显示提示
2. 点击"查看建议"按钮
3. 在弹出窗口中选择要保留的网站
4. 选择操作：
   - **保留选中，删除其他**：保留选中的网站，删除其他相似网站
   - **忽略建议**：暂时不处理这个建议

## ⏰ 定时任务

系统会在每周日凌晨2点自动执行相似度检查，检测所有网站之间的相似度，并生成合并建议。

## 🛠️ API接口

### GET /api/websites
获取所有网站数据

### POST /api/websites
添加新网站
```json
{
  "url": "https://example.com",
  "name": "示例网站" // 可选
}
```

### DELETE /api/websites/:id
删除指定网站

### PUT /api/websites/:id
更新网站信息

### GET /api/websites/suggestions
获取相似度建议

### POST /api/websites/suggestions/:id/action
处理相似度建议
```json
{
  "action": "merge", // 或 "dismiss"
  "keepIds": ["id1", "id2"]
}
```

- 网站列表
- 分类列表
- 相似度建议

## 📝 注意事项

- 确保输入的网址格式正确（包含 http:// 或 https://）
- 某些网站可能无法获取图标，系统会使用默认图标
- 相似度检测需要访问网站内容，请确保网络连接正常
- 建议定期查看和处理相似度建议，保持网站列表整洁
